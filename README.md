# Bravel

ИИ-агент для терминала Windows и Linux. Опишите задачу обычными словами — Bravel получит нужные сведения о компьютере, предложит команды и разберёт результат их выполнения.

[![Tests](https://github.com/coylll-dev/Bravel/actions/workflows/tests.yml/badge.svg)](https://github.com/coylll-dev/Bravel/actions/workflows/tests.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

```text
bravel

bravel › Найди самые большие файлы в папке Downloads, ничего не удаляй
bravel › Какие процессы сейчас занимают больше всего памяти?
bravel › Запусти Deep Rock Galactic
```

Bravel написан на Python. Для ответов нужен API выбранной модели: поддерживаются Gemini, OpenAI, OpenRouter и сервисы с OpenAI-совместимым API, включая локальные серверы.

## Что он умеет

- Работать с файлами: искать, читать текст, создавать и изменять текстовые файлы.
- Находить установленные приложения и игры Steam, предлагать их запуск.
- Исследовать процессы, сеть, диски и другие сведения о системе.
- Составлять команды для PowerShell, CMD или Bash, объяснять их и анализировать вывод.
- Продолжать задачу в несколько шагов, учитывая уже полученные результаты.
- Сохранять диалоги и загружать их позже.

Для типовых наблюдений агент использует локальные инструменты. Если нужного действия или показателя в них нет, он может составить shell-команду. Отдельные команды Bravel для каждой задачи учить не нужно — список программ или проверку сети можно попросить прямо в чате.

## Установка

Нужен **Python 3.10 или новее**. Скачайте [install.py](https://raw.githubusercontent.com/coylll-dev/Bravel/main/install.py) и запустите его из папки загрузки.

**Windows — CMD или PowerShell:**

```text
python install.py
```

**Linux:**

```bash
python3 install.py
```

Установщик создаст отдельное Python-окружение, установит Bravel и откроет настройку API. Выберите провайдера, модель и введите ключ; ключ при вводе скрыт. Git и ручная активация окружения не требуются. На Linux может понадобиться пакет `python3-venv` из репозитория дистрибутива.

После установки откройте новый терминал:

```text
bravel --version
bravel
```

На Windows команда добавляется в пользовательский PATH. Если уже открытый терминал её не видит, закройте все окна терминала и откройте CMD или PowerShell из меню Пуск. Можно запустить Bravel напрямую:

```bat
"%LOCALAPPDATA%\Bravel\venv\Scripts\bravel.exe"
```

В PowerShell используйте `& "$env:LOCALAPPDATA\Bravel\venv\Scripts\bravel.exe"`.

Каталог установки на Linux — `$XDG_DATA_HOME/bravel` или `~/.local/share/bravel`. При стандартной установке команда становится доступна через подключение в Bash. Прямой запуск: `~/.local/share/bravel/venv/bin/bravel`.

Чтобы установить только CLI без подключения к профилю оболочки, добавьте `--no-profile` к команде установщика. На Linux в таком случае используйте полный путь к программе или добавьте `venv/bin` в PATH самостоятельно.

## Как пользоваться

### Диалог

`bravel` и `bravel chat` открывают чат в терминале. Напишите задачу, прочитайте предложенный план и подтвердите его, если команды вам подходят.

На Windows агент по умолчанию использует PowerShell, даже если Bravel открыт из CMD. На Linux — Bash. Оболочку можно выбрать явно:

```text
bravel chat --shell cmd
```

**Подтверждение:** `Y` разрешает весь показанный план; Enter или `n` отменяют. Для действий с повышенным риском требуется `RUN`. Следующий план требует нового подтверждения. Системные метаданные агент может получать без отдельного вопроса; чтение содержимого файлов требует подтверждения, запись показывает полный текст и требует `RUN`.

Enter отправляет запрос, **Ctrl+J** вставляет новую строку. Если сочетание не работает в вашем терминале, нажмите последовательно Esc и Enter. Стрелки ↑/↓ возвращают предыдущие запросы, Tab дополняет команды чата. Ctrl+C отменяет запрос или останавливает выполняемую команду.

| Команда в чате | Назначение |
| --- | --- |
| `/help` | Все команды и сочетания клавиш |
| `/cd <путь>`, `/pwd` | Сменить или показать рабочую папку |
| `/shell <имя>` | Выбрать `powershell`, `cmd` или `bash` |
| `/status` | Посмотреть провайдера, модель и настройки сессии |
| `/continue` | Ещё раз проанализировать последний результат |
| `/new` | Начать новый диалог |
| `/clear` | Очистить экран |
| `/save имя`, `/load имя` | Сохранить или загрузить диалог |
| `/sessions`, `/delete имя` | Посмотреть или удалить сохранённые диалоги |
| `/context`, `/privacy` | Посмотреть данные для API и правила их передачи |
| `/exit` | Выйти из Bravel |

Для просмотра планов без выполнения используйте `bravel chat --mode preview` или `/mode preview` внутри чата. Вернуться к подтверждениям: `/mode ask`. Режим `/mode read-only` автоматически запускает только команды из небольшого локального списка разрешённого чтения, а не любые команды, которые модель назвала безопасными.

### Одна задача

```text
bravel "Покажи свободное место на дисках"
bravel agent "Проверь сеть и объясни результат"
bravel ask --dry-run "Найди большие файлы в текущей папке"
bravel ask --shell bash "Покажи мой локальный IP"
```

Короткая форма, `ask` и `agent` решают задачу с анализом результатов. `--dry-run` показывает план без выполнения. Рабочей папкой становится каталог, из которого запущен Bravel; её смена внутри агента не меняет папку родительского терминала. Переменные между отдельными shell-командами не сохраняются.

### Подключение к обычной оболочке

Установщик также добавляет интеграцию для PowerShell и Bash. С ней можно вызывать помощника, оставаясь в привычной консоли:

```text
ai "Покажи сетевые подключения"
# найди файлы больше 1 ГБ в этой папке
```

При вводе неизвестной команды Bravel предлагает исправление — например, `gti status` → `git status`. Простые опечатки исправляются без запроса к API; запуск всё равно нужно подтвердить. Ошибки уже известных команд автоматически не перехватываются. Их можно описать в чате или передать в `bravel fix "команда"`.

Интеграция требует загруженного профиля. Установщик **не меняет политику выполнения PowerShell**. Если профиль запрещён, обычный `bravel` продолжает работать без него. В CMD доступны чат и прямые команды CLI; перехват `#` и неизвестных команд не поддерживается. Zsh и fish пока не поддерживаются.

## Настройка API

```text
bravel configure
bravel configure --provider gemini
bravel configure --provider openrouter
```

Мастер предлагает URL и модель для выбранного провайдера. Укажите модель, доступную вашему ключу. Для другого роутера или локального сервера выберите `compatible` и задайте его базовый URL и идентификатор модели.

Настройки хранятся в `~/.config/bravel/.env` на обеих ОС; на Windows это `%USERPROFILE%\.config\bravel\.env`. `.env` в корне проекта не нужен и автоматически не читается. [`.env.example`](.env.example) — шаблон параметров.

Пример для совместимого роутера:

```dotenv
AI_PROVIDER=compatible
AI_API_BASE_URL=https://your-router.example/v1
AI_API_KEY=your-api-key
AI_MODEL=your-model-id
```

| Параметр | Что задаёт |
| --- | --- |
| `AI_PROVIDER` | `openai`, `gemini`, `openrouter` или `compatible` |
| `AI_API_BASE_URL` | Базовый URL API; мастер подставляет его для известных провайдеров |
| `AI_API_KEY` | Ключ выбранного сервиса |
| `AI_MODEL` | Точный идентификатор модели |
| `AI_REQUIRE_KEY` | `false` для локального сервера без ключа |
| `AI_JSON_MODE` | `false`, если совместимый сервис не поддерживает JSON mode |
| `AI_TIMEOUT` | Ожидание ответа API: 1–300 секунд |
| `AI_MAX_STEPS` | Максимум действий в одном плане: 1–10 |
| `AI_COLOR` | `auto`, `always` или `never`; также учитывается `NO_COLOR` |

Вместо общего ключа можно использовать `GEMINI_API_KEY`, `OPENROUTER_API_KEY` или `OPENAI_API_KEY`. `AI_API_KEY` имеет приоритет. Переменные окружения переопределяют значения из файла; `BRAVEL_ENV` задаёт путь к другому конфигу.

Прямой Gemini использует `generateContent`, остальные провайдеры — OpenAI-совместимый Chat Completions. Для удалённых сервисов требуется HTTPS; HTTP разрешён для локальных адресов `localhost`, `127.0.0.1` и `::1`.

Проверка локальных настроек — `bravel doctor`. Проверка подключения к модели — `bravel doctor --api`; она отправляет короткий API-запрос и может расходовать токены.

## Обновление и удаление

```text
bravel update
bravel rollback
bravel uninstall
```

Эти команды управляют установкой, созданной через `install.py`. Дождитесь сообщения о завершении: на Windows операция выполняется отдельным процессом. Затем перезапустите Bravel.

Обновление сохраняет один снимок предыдущей версии для `rollback`. Настройки API и сохранённые диалоги при откате остаются. Удаление убирает программу и её подключение к оболочке, сохраняя конфиг. `bravel uninstall --purge` удаляет также стандартный `.env` с ключом.

Если CLI недоступен, скачанный установщик поддерживает `python install.py update` и `python install.py uninstall`; на Linux используйте `python3`.

## Данные и ограничения

Bravel отправляет выбранному API ваш запрос, сведения об ОС, оболочке и рабочей папке, историю диалога и результаты действий агента. Чтение файлов не происходит само по себе: их содержимое попадает в контекст после подтверждённого чтения. История обычного терминала не собирается.

Диалог по умолчанию хранится в памяти. `/save` сохраняет его на диск, а `bravel chat --session имя` включает загрузку и автосохранение. При загрузке старые планы не получают разрешения на запуск. Известный API-ключ и типовые секреты маскируются в контексте и сохранённой истории, но произвольные секреты могут остаться нераспознанными.

- Команды выполняются с правами вашего пользователя. Оценка риска и подтверждение не заменяют песочницу — прочитайте план перед запуском.
- Вывод и поиск ограничены по объёму. Агент получает начало и конец большого вывода с отметкой о пропущенной середине; отсутствие записи в такой выдержке не доказывает её отсутствие на компьютере.
- На одну задачу отводится до восьми циклов действий. После этого агент должен подвести итог по собранным данным и указать, что осталось неизвестным.
- Shell-команды не получают интерактивный ввод. Установка, требующая диалога с пользователем, может не сработать внутри агента.
- Встроенного веб-поиска, управления мышью и распознавания экрана пока нет.
- Модель может составить неверную команду или ошибочно истолковать результат. Проверка синтаксиса PowerShell/Bash помогает выявить часть ошибок, но не проверяет смысл команды.

## Разработка

```text
git clone https://github.com/coylll-dev/Bravel.git
cd Bravel
```

**Windows — без активации окружения:**

```text
python -m venv .venv
.venv\Scripts\python.exe -m pip install -e .
.venv\Scripts\python.exe -m unittest discover -s tests -v
.venv\Scripts\bravel.exe
```

**Linux:**

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -e .
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/bravel
```

Тесты используют подставные ответы и локальный HTTP-сервер; настоящий API-ключ не нужен. GitHub Actions проверяет Windows и Linux на Python 3.10, 3.12 и 3.13, включая интеграции оболочек, установку, обновление, откат и удаление.
